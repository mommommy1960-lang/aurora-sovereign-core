# Reviewers Start Here

Aurora Sovereign Core is a simulation-only reference core for bounded memory, consent-gated assistance, transparent planning, and safe shutdown.

## Review focus

Test that unknown actions are denied, trust never expands authority, shutdown remains independently controlled, and state changes are attributable and auditable.

## Evidence boundary

Aurora does not claim consciousness, personhood, hardware readiness, or autonomous real-world authority.
