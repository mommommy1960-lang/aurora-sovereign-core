# Aurora Sovereign Core

Aurora is a simulation-only reference core for transparent planning, bounded
memory continuity, consent-gated assistance, and independently controlled safe
shutdown.

## Evidence level

**Prototype / simulation.** This repository does not establish consciousness,
personhood, hardware readiness, or autonomous real-world authority.

## Run

```bash
python -m aurora.demo
python -m pytest -q
```

Aurora begins dormant. Unknown actions are denied. Trust, affection, memory,
identity, urgency, and self-preservation never expand permission scope.
